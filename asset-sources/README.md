# Source assets

These files are retained for reference and are not bundled into the website.

- `originals/`: original uploaded campus photos, Code for Good logo, and
  Quotvero favicon. Site-ready copies live under `src/assets/`.
- `legacy/`: previous VP logos, alternate headshot, and unused starter images.
- `models/`: original camera ZIP. The extracted runtime model and its license
  remain under `public/models/fujifilm-x-t3/`.

Add new source uploads here instead of leaving them in the project root.
